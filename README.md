# שירות מזג אוויר לימות המשיח

שירות API לקבלת מזג אוויר ולהשמעת התחזית במערכת הטלפונית של ימות המשיח.

המערכת משתמשת בשירותי **Open-Meteo** לאיתור יישובים ולקבלת נתוני מזג אוויר. אין צורך במפתח API.

## מה השירות עושה?

- מאפשר לבחור יישוב מתוך רשימת יישובים בעברית.
- מקבל גם שם יישוב בפרמטר `town` או `city`.
- מקריא את מצב מזג האוויר, הטמפרטורה, התחושה, הרוח והלחות.
- מוסיף המלצת לבוש בהתאם למזג האוויר: חולצה מכופתרת או ארוכה, סוודר, קרדיגן, ז׳קט, מעיל חורף או גשם, חליפה, מכנסיים ארוכים, נעליים סגורות, צעיף וכובע.
- כולל 30 נוסחי פתיחה יומיים ו־10 נוסחי סיום מתחלפים לפי היום בשנה, לצד המלצות לבוש שמשתנות לפי הטמפרטורה, התחושה, הרוח והגשם.
- מתאים את הניסוח לתנאים בפועל, כדי שההודעה תישמע טבעית ונעימה ולא כמו רשימת נתונים יבשה.
- מחזיר פלט בפורמט `read=` המתאים לחיבור לימות המשיח.

## כתובת השירות

לאחר פריסה ב־Vercel:

```
https://YOUR-PROJECT.vercel.app/api/weather?town=ירושלים
```

אפשר להשתמש גם בפרמטר:

- `town` — שם היישוב בעברית או באנגלית.
- `city` — שם חלופי ליישוב.
- `wm_nav`, `town_choice`, `ApiPhoneInput` או `val` — ערך הבחירה המספרית מתוך תפריט היישובים.

אם לא נשלח שם יישוב או מספר בחירה תקין, השירות מחזיר תפריט לבחירת יישוב.

## דוגמה להקראה

לדוגמה, ביום קריר השירות עשוי לומר:

> שלום וברוכים הבאים לשירות מזג האוויר. מזג האוויר בירושלים כעת קריר. הטמפרטורה היא 12 מעלות, אך התחושה קרה יותר. מומלץ לצאת עם חולצה ארוכה, סוודר או ז'קט, ואפשר להוסיף מעיל אם יוצאים לזמן ממושך. שיהיה לכם יום נעים ובריא!

ההמלצה משתנה בהתאם לטמפרטורה, לתחושת הקור, לרוח ולמשקעים.

## פריסה ב־Vercel

1. נכנסים ל־Vercel ובוחרים **Add New Project**.
2. מייבאים את המאגר הזה מ־GitHub.
3. משאירים את הגדרות ברירת המחדל.
4. מוודאים שהפרויקט רץ עם Node.js 18 ומעלה.
5. לוחצים **Deploy**.
6. בודקים את הכתובת עם הדוגמה שלמעלה.

## חיבור לימות המשיח

יש להגדיר את השלוחה כך שתשלח לכתובת ה־API את שם היישוב או את מספר הבחירה שנקלט בתפריט. השירות מחזיר טקסט בפורמט `read=` להקראה במערכת.

**חשוב:** הגרסה הנוכחית מבקשת בחירת יישוב בכל פעם שלא נשלח לה יישוב בבקשה. שמירת עיר לפי מספר טלפון וזיהוי אוטומטי של מתקשר הם שדרוג נפרד שעדיין דורש חיבור למסד נתונים.

## שמירת עיר מועדפת ב-Google Sheets

המאגר כולל חיבור אופציונלי לשמירת עיר מועדפת לפי מספר המתקשר שמתקבל בפרמטר `ApiPhone`.

### התקנה חד-פעמית

1. פותחים [Google Apps Script](https://script.google.com/) ויוצרים פרויקט חדש.
2. מעתיקים לפרויקט את הקוד שבקובץ [google-apps-script.gs](./google-apps-script.gs).
3. מריצים פעם אחת את הפונקציה `setup` ומאשרים את ההרשאות. הפונקציה יוצרת גיליון עם העמודות: מספר טלפון, עיר מועדפת, עודכן בתאריך.
4. פותחים את יומן הביצוע ומעתיקים את `SPREADSHEET_URL` ואת `API_SECRET` שמופיעים בו.
5. בוחרים **Deploy → New deployment → Web app**.
6. מגדירים **Execute as: Me** ו-**Who has access: Anyone**, ואז מבצעים פריסה ומעתיקים את כתובת ה-Web app.
7. ב-Vercel נכנסים לפרויקט → **Settings → Environment Variables**, ומוסיפים:
   - `GOOGLE_SHEETS_WEB_APP_URL` — כתובת ה-Web app שהתקבלה בפריסה.
   - `GOOGLE_SHEETS_SECRET` — הערך של `API_SECRET` מיומן הביצוע.
8. מבצעים Redeploy לפרויקט ב-Vercel.

### התנהגות המערכת

- בשיחה שבה המתקשר בוחר מספר עיר, הבחירה נשמרת לפי `ApiPhone`.
- בשיחה הבאה, אם לא נשלחה בחירה חדשה, השירות טוען את העיר השמורה ומשמיע את התחזית.
- בחירה חדשה מחליפה את העיר הקודמת.
- אם אין עדיין עיר שמורה או שהחיבור ל-Sheets לא הוגדר, השירות חוזר לתפריט בחירת הערים הרגיל.
- אם לא נשלח `ApiPhone`, השירות ממשיך לעבוד כרגיל אך אינו יכול לשמור העדפה אישית.

הגיליון נוצר בחשבון Google שמריץ את `setup`. אין לשתף את כתובת ה-Web app ואת סוד ה-API בפומבי.

## פרטיות

מספר הטלפון והעיר המועדפת נשמרים בגיליון Google Sheets שבבעלות בעל הפרויקט. יש להגביל את הגישה לגיליון למי שצריך לנהל אותו בלבד.

## פורמטי פלט וסימולטור

בקוד ובסימולטור נשמרים שמות הפורמטים והקידומות הבאים:

- `read` — פקודת הקראה וקבלת קלט; קידומות תוכן: `t-` לטקסט ו־`n-` לערך מספרי. מבנה השדות המלא מוצג בסימולטור.
- `id_list_message` — הודעת רשימה; קידומות התוכן האפשריות לפי המפרט שנמסר: `t-`, `n-`, `date-`, `dateH-`.
- `api_answer` — שמות הפעולות שהוגדרו: `read`, `id_list_message`, `go_to_folder`, `noop`.

**הערה:** עבור `api_answer` לא הוגדר כאן מבנה תחביר מלא, ולכן לא הומצא פורמט ביצוע. שירות מזג האוויר עצמו ממשיך להחזיר כרגע תשובות בפורמט `read=`; הסימולטור מאפשר להציג דוגמאות ולבדוק את זרימת השיחה.
